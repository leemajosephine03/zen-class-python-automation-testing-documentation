## What is Continuous Integration (CI) 
* In this method, all team members integrate there work at one place at least once a day 
* Once the application is built it will tested immediately
* Once, the CI happens for a code the application is built and tested immediately

## What is Continuous Delivery (CD)
* It is a method, where the development team creates the software or the application in a short period of time
* With CD it helps us to develop, build, test and release the software for production environments for deployment
* CD helps to to achieve our objectives by Reducing time, Reducing cost, Creating the software within the timeline set by project charter

## Jenkins Pipeline

~~~groovy
pipeline{
    agent any
    stages{
        stage('Checkout'){
            steps{
                checkout scmGit(branches: [[name: '*/main']], extensions: [], userRemoteConfigs:[[url: 'https://github.com/basil-hameed/Jenkins-EB1.git']])
            }
        }
        stage('Build'){
            steps{
                git branch: 'main', url: 'https://github.com/basil-hameed/Jenkins-EB1.git'
                bat 'pytest'
            }
        }
    }
}
~~~
