## Unit Testing
* Unit testing is a software testing technique where individual units or components of a program are tested in isolation to ensure they function correctly.
* The primary goal is to validate that each unit of the software performs as expected.
* It helps in:

* Detecting bugs early in development.

* Simplifying debugging and maintenance.

* Improving code reliability and refactoring safety.

## Steps involved in unit testing
* **Arrange** – Set up the test data and conditions.
* **Act** – Execute the function or method being tested.
* **Assert** – Verify that the result matches the expected output.


## Writing Your First Unit Test Using unittest Module
* **Example 1**
* Testing a Simple Function

~~~ python
# math_operations.py

def add(a, b):
    return a + b


# test_math_operations.py
import unittest
from math_operations import add

class TestMathOperations(unittest.TestCase):
    def test_add(self):
        self.assertEqual(add(2, 3), 5)
        self.assertEqual(add(-1, 1), 0)
        self.assertEqual(add(0, 0), 0)
        self.assertNotEqual(add(2, 2), 8)
        self.assertGreater(add(2, 5), 6)

if __name__ == "__main__":
    unittest.main()
~~~

## Python Exception Handling With Examples
## What is Exception Handling?
* Exception handling in Python is a mechanism that allows a program to handle runtime errors gracefully instead of crashing.
* It helps in identifying, handling, and recovering from errors that might occur during program execution.

Common causes of exceptions include:
- Division by zero
- Accessing an undefined variable
- Invalid type operations
- File not found errors

---
## Using `try` and `except` Blocks
Python provides the `try-except` construct to handle exceptions.

### Example: Handling Division by Zero
```python
try:
    result = 10 / 0  # This will cause a ZeroDivisionError
except ZeroDivisionError:
    print("Error: Division by zero is not allowed.")
```
**Output:**
```
Error: Division by zero is not allowed.
```

---
## Handling Multiple Exceptions
You can handle multiple exceptions by specifying multiple `except` blocks.

### Example: Handling Multiple Errors
```python
try:
    num = int(input("Enter a number: "))
    result = 10 / num
    print(result)
except ZeroDivisionError:
    print("Error: Cannot divide by zero.")
except ValueError: # string
    print("Error: Invalid input. Please enter a number.")
```

---
## Using `else` and `finally`
- **`else`**: Runs if no exceptions occur.
- **`finally`**: Always executes, regardless of exceptions.

### Example:
```python
try:
    num = int(input("Enter a number: "))
    result = 10 / num
except ZeroDivisionError:
    print("Error: Cannot divide by zero.")
else:
    print(f"Result: {result}")
finally:
    print("Execution completed.")
```

---
## Raising Exceptions Manually
Use `raise` to manually trigger exceptions.

### Example:
```python
def check_age(age):
    if age < 18:
        raise ValueError("Age must be at least 18.")
    return "Access granted."

try:
    print(check_age(16))
except ValueError as e:
    print("Exception:", e)
```

**Output:**
```
Exception: Age must be at least 18.
```

---
## Custom Exceptions
You can define custom exception classes by inheriting from `Exception`.

### Example:
```python
class CustomError(Exception):
    pass

try:
    raise CustomError("This is a custom exception.")
except CustomError as e:
    print("Caught exception:", e)
```

## Intro to Python PIP
* PIP is the standard package manager of Python
* We can use pip to install those modules/libraries which are not part of Python core.
* Packages can be searched here in pypi website, https://pypi.org/ 

**Verify PIP is present in your system**
~~~sh
pip --version
~~~

**Install any Python module/library**
~~~sh
pip install <package_name>

pip install selenium

pip install termcolor
~~~

## **Using a Package**
* Once the package is installed, it is ready to use.
* Import the "camelcase" package into your project.

~~~python
# Import colored, cprint

from termcolor import colored, cprint
 
print("Hello World!!!", 'red')
cprint("Hello World!!!", 'red')
print(colored("Hello World!!!", 'light_cyan'))
print(colored("Hello World!!!", 'green', attrs=['underline']))

# Import and use "camelcase":

import camelcase

c = camelcase.CamelCase()

txt = "hello world"

print(c.hump(txt))
~~~

**List all installed modules**
~~~sh
pip list
~~~

**Uninstall Python modules using PIP**
~~~sh
pip uninstall <package_name>

pip uninstall pandas
~~~

**Using Requirements.txt file**

* This requirements.txt file contains a list of Python packages/modules in a text file.
* You can install a bunch of Python packages at one go without wasting your time.
* Create a simple requirements.txt file add the name of the Python packages/modules in every independent file save it and run using the command given below :- 

~~~sh
pip install -r requirements.txt
~~~

**Create a Requirements.txt file using PIP**
~~~sh
pip freeze > requirements.txt
~~~

**Package information**
~~~sh
pip show <package_name>

pip show selenium
~~~
