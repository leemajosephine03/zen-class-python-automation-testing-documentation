**Python Lambda Expressions**
* A lambda function is a small anonymous function.
* Lambda functions are functions without any name
* A lambda function can take any number of arguments, but can only have one expression.

**Syntax**

Variable_name = lambda arguments : expression

# normal functions vs lambda 
~~~python
def display_name(data):
  return data

print(display_name("basil"))

# lambda functions
x = lambda a : a + 10
print(x(5))

# lambda functions
result = lambda data : data

print(result("guvi"))
~~~

## Reduce() function

* The reduce function is part of the functools module, and it is used to reduce the iterable to a single result.
* Suppose we have 5 integer items and we need a sum of all integers.
* Ex. numbers = [1, 2, 3, 4]
* (1, 2) = 3,
* (3, 3) = 6
* (6, 4) = 10

~~~ python
from functools import reduce

numbers = [1, 2, 3, 4]

# Using reduce to calculate the sum
result = reduce(lambda x, y: x + y, numbers)

print(result)  # Output: 10


# Example with initializer:
from functools import reduce

numbers = [1, 2, 3, 4]

# Using reduce to calculate the sum with an initializer
result = reduce(lambda x, y: x + y, numbers, 10)

print(result)  # Output: 20

# Step-by-Step:
Start with the initializer value 10.
Apply lambda(10, 1) → result = 11
Apply lambda(11, 2) → result = 13
Apply lambda(13, 3) → result = 16
Apply lambda(16, 4) → result = 20

~~~

## **Python Generators**

* Generators are functions, which returns us an iterator that has a sequence of results when iterated through.
* It helps to save the memory of our machine
* Because the “return” statement returns everything to us and it clogs the memory if the output is big and humongous. 
* Generator have "yield" instead of "return".

~~~python

def suman_number_generator(number):
  result = 0
  while result < number:
    yield result
    result = result + 1

for data in suman_number_generator(20):
  print(data) 
 
~~~

1. Write a Python program to YIELD squares of numbers ?
~~~python
def square_numbers(max):
  n=1
  while n<=max:
    yield n**2
    n=n+1 
for data in square_numbers(5):
  print(data)
~~~

2. Write a Python program to YIELD reverse of a string ?

~~~python
def reverse_string(data):
  for index in range(len(data)-1, -1, -1):
    yield data[index]


for data in reverse_string('guvigeeks'):
  print(data)
~~~

## **Decorators**

* Decorators allowing us to add additional functionality to existing functions or methods, without changing their actual code.
* Simply, it takes another function as an argument and returns a new function with enhanced functionality.

~~~ python
def my_decorator(func):
    def wrapper():
        print("Something is happening before the function is called.")
        func()
        print("Something is happening after the function is called.")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()


# Example 1
# Decorating Type I
def make_pretty(func):
    # define the inner function 
    def inner():
        # add some additional behavior to decorated function
        print("I got decorated")

        # call original function
        func()
    # return the inner function
    return inner

# define ordinary function
def ordinary():
    print("I am ordinary")
    
# decorate the ordinary function
decorated_func = make_pretty(ordinary)

# call the decorated function
decorated_func()

# Decorating Type II
def make_pretty(func):
    # define the inner function 
    def inner():
        # add some additional behavior to decorated function
        print("I got decorated")

        # call original function
        func()
    # return the inner function
    return inner

# define ordinary function with decorator
@make_pretty
def ordinary_func():
    print("I am ordinary")
    
# call the ordinary function()
ordinary_func()

~~~

## **Regex**
* A RegEx, or Regular Expression, is a sequence of characters that forms a search pattern.
* Import the re module to start using regular expressions.

**Metacharacters**
* []	A set of characters	"[a-m]"	
* \	  Signals a special sequence (can also be used to escape special characters)	"\d"	
* .	  Any character (except newline character)	"he..o"	
* ^	  Starts with	"^hello"	
* $	  Ends with
* {}	Exactly the specified number of occurrences "he.{2}o"
* +	One or more occurrences	"he.+o"

~~~python
import re

class MyRegularExpression:
 
  # program for validating PAN CARDS
  def validate_pan_card(self, pan_card):
    """
    LOGIC
   
    1.) 10 Alphanumeric string
    2.) First 5 characters are alphabets
    3.) Next 6 to 9 characters are Integers
    4.) The 10th character will be alphabet
    """  
    pattern = r"^[A-Z]{5}[0-9]{4}[A-Z]{1}$"
    if re.match(pattern, pan_card):
      return True
    else:
      return False
   
  def validate_email_id(self, email):
    """
    LOGIC
    hari@gmail.in
    1.) it is an alpha-numeric string
    2.) it should have @
    3.) alphanumeric string on the LHS & RHS of @ symbol
    4.) A . symbol
    5.) A domain after the . symbol of either 2 to 6 character long
    """
   
    pattern = r"^[a-z0-9_.]+@[a-z0-9]+\.[a-z]{2,6}"
    if re.match(pattern, email):
      return True
    else:
      return False
 
  def validate_indian_mobile_number(self, mobile_number):
    pattern = r"^[9876][0-9]{9}$"
    if re.match(pattern, mobile_number):
      return True
    else:
      return False
 
  def validate_pin_code(self, pincode):
    """
    LOGIC
   
    1.) it is of 6 characters only
    2.) the first character should be from 1 to 9
    """
    pattern = r"^[1-9][0-9]{5}"
    if re.match(pattern, pincode):
      return True
    else:
      return False
~~~
