## Usage of Keywords in Robot Framework

* Keywords are the building blocks of Robot framework
* It makes the test-script reusable 
* With keywords we can able to make out code more modular

## Page Object Model (POM) using Robot Framework
* Page Object Model (POM) is a design pattern
* It is used in automation testing frameworks to help organize and maintain test-scripts for our web applications

## Benefits of Page Object Model
* Code reusability
* Test-script maintainability
* Test-script readability
* Test-script reliability

## Folder Structure


Break the code into a PageObject robot file. This file should have
*** Settings ***
*** Variables ***
*** Keywords ***

In Robot Test-Script file you should have
*** Settings ***
*** Test Cases ***
Kindly add the PageObjects/HomePage.robot file into your test-script using the Keyword “Resource”

## HomePage.robot

~~~robot
*** Settings ***


# HomePage.robot


Documentation   Page Objects for HomePage testing


Library     SeleniumLibrary


*** Variables ***


${BASE_URL}     https://automationplayground.com/crm/index.html
${USERNAME}     basil@gmail.com
${PASSWORD}     Secret@123
${EMAIL}        tester@example.com
${FIRST_NAME}   Automation
${LAST_NAME}    Tester
${CITY}         Chennai


*** Keywords ***


Start automation
   [Documentation]     Start automation
   [Tags]  Start
   Open Browser       ${BASE_URL}      chrome
   Maximize Browser Window
   Set Browser Implicit Wait    10s
   Capture Page Screenshot     ../ScreenShots/image_1.png


Sign-in into the application
   [Documentation]     Sign-in into the application
   [Tags]      CLick Sign-in button
   Click Link    name=sign-in-link
   Capture Page Screenshot     ../ScreenShots/image_2.png


Add Sign-up credentials
   [Documentation]     Add Sign-up credentials
   [Tags]      Enter username password
   Input Text    id=email-id    ${USERNAME}
   Input Text    id=password    ${PASSWORD}
   Click Button    id=submit-id
   Capture Page Screenshot     ../ScreenShots/image_3.png


Add a new customer
   [Documentation]     Add a new customer
   [Tags]      Add new customer
   Click Link    id=new-customer
   Input Text    id=EmailAddress       ${EMAIL}
   Input Text    id=FirstName    ${FIRST_NAME}
   Input Text    id=LastName    ${LAST_NAME}
   Input Text    id=City    ${CITY}
   Select From List By Value    id=StateOrRegion       AK
   Select Radio Button    gender    male
   Scroll Element Into View    xpath=//button[@type='submit']
   Click Button    xpath=//button[@type='submit']
   Capture Page Screenshot     ../ScreenShots/image_5.png


Confirm the new user
   [Documentation]     Confirm the new user
   [Tags]      Confirm user addition
   Wait Until Page Contains    Success! New customer added.
   Capture Page Screenshot     ../ScreenShots/image_6.png


Shutdown automation
   [Documentation]     Shutdown automation
   [Tags]      Shutdown
   Close All Browsers
~~~

## 📁 `PageObjects/LoginPage.robot`

```robot
*** Settings ***
Library           SeleniumLibrary
Resource    ../Resources/Variables.robot

*** Keywords ***
Click Login Button
    Wait Until Element Is Enabled    id=login2
    Click Element    id=login2

Enter Login Credentials
    Wait Until Element Is Visible    id=loginusername
    Input Text    id=loginusername    ${USERNAME}
    Input Text    id=loginpassword    ${PASSWORD}
    Click Button    xpath=//button[text()='Log in']


Verify Login Successful
    Wait Until Element Is Visible    id=nameofuser
    Element Should Contain    id=nameofuser    Welcome
```

## 📁 `PageObjects/ProductPage.robot`

```robot
*** Settings ***
Library           SeleniumLibrary

*** Keywords ***
Verify Product Grid Is Visible
    Element Should Be Visible    xpath=//div[@id='tbodyid']//div[contains(@class,'col-lg-4')]

Click First Product
    Click Element    xpath=(//div[@id='tbodyid']//a)[1]
    Page Should Contain Element    //a[text()='Add to cart']

Verify Product Details Page
    Wait Until Page Contains Element    xpath=//h2[@class='name']
    Element Should Be Visible    xpath=//h2[@class='name']
```
