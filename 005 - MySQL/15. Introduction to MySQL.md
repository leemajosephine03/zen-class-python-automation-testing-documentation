## 1. Database
* A database is a collection of interrelated data that helps in the retrieval, insertion, and deletion of data from the database.
* The data are stored in the form of tables, charts, schemas, reports, etc.

## 2. Database Management System
* A Database Management System is a software system designed to manage and organize data in a structured manner.
* It allows users to create, modify, and query a database.
* DBMS provides an environment to store and retrieve data in convenient and efficient manner.

## Key Features of DBMS
* Data storage and retrieval
* Controlling concurrent access
* Data integrity and security
* Backup and recovery

## Classification of DBMS
* DBMS can be classified into two types:
1. Relational Database Management System (RDBMS) and
2. Non-Relational Database Management System (NoSQL)

## Relational Database Management System (RDBMS) or SQL
* SQL stands for Structured Query Language.
* Data is organized in the form of tables and each table has a set of rows and columns.
* The data are related to each other through primary and foreign keys.

## NoSQL DBMS 
* Data is organized in the form of key-value pairs, documents, graphs, or column-based.
* These DBMS will handle large-scale, high-performance scenarios.

## 3. Introduction to MySQL/MariaDB
* MySQL is an open-source relational database management system.
* It uses Structured Query Language (SQL) for managing and querying data.
* It is widely used in web applications, enterprise systems, and cloud-based databases.

## Features
* Fast & Scalable – Handles large databases efficiently.
* Multi-User Support – Multiple users can access the database simultaneously.
* Security – Provides authentication, encryption.
* Cross-Platform – Works on Windows, Linux, and macOS.
* Backup – Supports database replication and backup strategies.
  
## 3. Database Languages XXX
1. Data Definition Language - database schemas and descriptions (CREATE, ALTER, DROP, TRUNCATE)
2. Data Manipulation Language - data manipulation (SELECT, INSERT, UPDATE, DELETE)
3. Data Control Language - grant and revoke permissions to users (GRANT, REVOKE)

## 4. Basic MySQL Commands with CRUD operations
1. Display databases
   
   **SHOW DATABASES;**

2. Create a new database
   
   **CREATE DATABASE <database_name>;**

   **CREATE DATABASE pat_learners;**
   
3. Use a particular database
   
   **USE <database_name>;**

   **USE pat_learners;**
   
4. Display the list of tables present inside a MySQL database
   
   **SHOW TABLES;**
   
5. Create a MySQL table inside MySQL database
    
   **CREATE TABLE student (id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(20), email_id VARCHAR(20));**
   
   NOTE # The column ID is Integer data type and auto-increment which means that ID column will be taken care of by the MySQL server itself.
   You do not need to fill the ID for this MySQL table.

6. Insert data into a MySQL database
    
   **INSERT INTO student (name, email_id) VALUES("suman gangopadhyay", "suman@guvi.in");**

7. Insert multiple data into a MySQL table
    
    **INSERT INTO student (name, email_id) VALUES ("tanu", "tanu@example.com"), ("nitin", "nitin@example.com"), ("priya", "priya@example.com");**

8. Update a data in MySQL table
    
    **UPDATE student SET name="Suman Ganguly" WHERE id=1;**

9. Delete data from MySQL table
   
    **DELETE FROM student WHERE id=1;**

10. Display the details of a MySQL table
    
   **DESCRIBE table_name;**

11. Fetch data from a MySQL table

   **SELECT * FROM user;**

12. Delete a MySQL database
   
   **DROP DATABASE <database_name>;**
   
   **DROP DATABASE ml_practice;**

## 5. Normalization
* Normalization is a database design principle for organizing data in an organized and consistent way.
* It helps you avoid redundancy and maintain the integrity of the database.

## Purpose of Normalization?
* The main purpose of database normalization is to avoid complexities, eliminate duplicates, and organize data in a consistent way.
* The data is divided into several tables linked together with relationships.
* 1NF, 2NF, and 3NF are the first three types of database normalization.
* They stand for first normal form, second normal form, and third normal form.

## Primary Key and Foreign Key 
* Primary keys serve as unique identifiers for each row in a database table.
* Foreign keys link data in one table to the data in another table.

![1_wr_PNTP9fQHxXeMydaSfnQ](https://github.com/user-attachments/assets/f4357443-90a1-4aac-b0cb-a47eaab3b232)

~~~ sql
1. Create Students Table

CREATE TABLE Students (
    Student_ID INT PRIMARY KEY,
    Last_Name VARCHAR(50),
    First_Name VARCHAR(50)
);

2. Create Classes Table

CREATE TABLE Classes (
    Class_ID INT PRIMARY KEY,
    Title VARCHAR(100),
    Description TEXT
);

3. Create Enrollments (Join Table)

CREATE TABLE Enrollments (
    Enrollment_ID INT PRIMARY KEY AUTO_INCREMENT,
    Student_ID INT,
    Class_ID INT,
    FOREIGN KEY (Student_ID) REFERENCES Students(Student_ID),
    FOREIGN KEY (Class_ID) REFERENCES Classes(Class_ID)
);
~~~
