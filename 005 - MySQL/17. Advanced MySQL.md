## **Step 1: Create the Database**
```sql
CREATE DATABASE BookStoreDB;
USE BookStoreDB;
```
This command **creates** the database and **switches to it**.

---

## **Step 2: Create Tables**
### **1. Customers Table**
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20) NOT NULL,
    email VARCHAR(20) UNIQUE NOT NULL
);
```
- `customer_id`: Primary Key with `AUTO_INCREMENT`  
- `email`: Must be **unique**

---

### **2. Books Table**
```sql
CREATE TABLE Books (
    book_id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(20) NOT NULL,
    author VARCHAR(20) NOT NULL,
    price INT NOT NULL,
    stock INT NOT NULL DEFAULT 0
);
```
- `book_id`: Primary Key  
- `price`: Stores book price  
- `stock`: Default value `0`

---

### **3. Orders Table**
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY AUTO_INCREMENT,
    customer_id INT,
    order_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    total_amount INT DEFAULT 0,
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);
```
- `customer_id` **(Foreign Key)** → References `Customers(customer_id)`  
- `ON DELETE CASCADE` → **If a customer is deleted, their orders are also deleted**  

---

### **4. OrderDetails Table (Many-to-Many Relationship)**
```sql
CREATE TABLE OrderDetails (
    order_detail_id INT PRIMARY KEY AUTO_INCREMENT,
    order_id INT,
    book_id INT,
    quantity INT,
    price INT,
    FOREIGN KEY (order_id) REFERENCES Orders(order_id),
    FOREIGN KEY (book_id) REFERENCES Books(book_id)
);
```
- **Foreign Keys**:
  - `order_id` references `Orders(order_id)`
  - `book_id` references `Books(book_id)`
- `ON DELETE CASCADE` → If an order is deleted, related order details are also deleted

## **1️⃣ Subqueries** (Query inside another query)
### **1.1 Find Customers Who Placed an Order**
```sql
SELECT name FROM Customers 
WHERE customer_id IN (SELECT customer_id FROM Orders);
```
👉 **Finds customers who have placed an order.**

### **1.2 Find the Most Expensive Book**
```sql
SELECT title, price FROM Books 
WHERE price = (SELECT MAX(price) FROM Books);
```
👉 **Finds the book with the highest price.**

### **1.3 Find Books That Have Been Ordered**
```sql
SELECT title FROM Books 
WHERE book_id IN (SELECT book_id FROM OrderDetails);
```
👉 **Lists books that have been ordered.**

## **2️⃣ Stored Procedure** (Reusable SQL Block)
### **2.1 Create a Procedure to Add an Order**
```sql
DELIMITER //

CREATE PROCEDURE PlaceOrder(IN p_customer_id INT, IN p_book_id INT, IN p_quantity INT)
BEGIN
    DECLARE book_price INT;
    DECLARE total_price INT;

    -- Get book price
    SELECT price INTO book_price FROM Books WHERE book_id = p_book_id;

    -- Calculate total price
    SET total_price = book_price * p_quantity;

    -- Insert into Orders table
    INSERT INTO Orders (customer_id, total_amount) VALUES (p_customer_id, total_price);

    -- Insert into OrderDetails table
    INSERT INTO OrderDetails (order_id, book_id, quantity, price) 
    VALUES (LAST_INSERT_ID(), p_book_id, p_quantity, total_price);
END //

DELIMITER ;
```
👉 **Creates a procedure to place an order.**

### **2.2 Call the Procedure**
```sql
CALL PlaceOrder(1, 2, 3);
```
👉 **Places an order for 3 copies of book `2` for customer `1`.**

## **3️⃣ Transactions** (Ensure all queries succeed or fail together)
### **3.1 Place an Order Only If Stock is Available**
```sql
START TRANSACTION;

-- Check stock
SELECT stock INTO @stock FROM Books WHERE book_id = 2;

IF @stock >= 1 THEN
    -- Reduce stock
    UPDATE Books SET stock = stock - 1 WHERE book_id = 2;

    -- Insert order
    INSERT INTO Orders (customer_id, total_amount) VALUES (1, 30);

    -- Insert order details
    INSERT INTO OrderDetails (order_id, book_id, quantity, price) 
    VALUES (LAST_INSERT_ID(), 2, 1, 30);

    -- Commit changes
    COMMIT;
ELSE
    -- Rollback if no stock
    ROLLBACK;
END IF;


**Use this only**

START TRANSACTION;

-- Insert an order
INSERT INTO orders (customer_id, total_amount) VALUES (1, 100);

-- Deduct stock
UPDATE books SET stock = stock - 1 WHERE book_id = 2;

-- Commit changes
COMMIT;

```
👉 **Only places an order if the book is in stock.**

## **4️⃣ Views** (Simplified Virtual Table)
### **4.1 Create a View for Order Summary**
```sql
CREATE VIEW OrderSummary AS
SELECT o.order_id, c.name, b.title, od.quantity, od.price
FROM Orders o
JOIN OrderDetails od ON o.order_id = od.order_id
JOIN Books b ON od.book_id = b.book_id
JOIN Customers c ON o.customer_id = c.customer_id;
```
👉 **Creates a simple view of orders.**

### **4.2 Use the View**
```sql
SELECT * FROM OrderSummary;
```
👉 **Shows a summarized order report.**
