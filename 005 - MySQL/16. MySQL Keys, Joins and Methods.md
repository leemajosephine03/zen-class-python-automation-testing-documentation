## 1. MySQL Built-in methods, having, group by, distinct
## Import file1.sql before execution

**1. Fetch certain columns from the MySQL table**

select username, gender, password from user_details;

**2. Fetch Distinct data from MySQL table**
* The **SELECT DISTINCT** statement is used to return only distinct (different) values.

select distinct last_name from user_details;

**3. SQL WHERE Clause fetching all columns**
* The WHERE clause is used to filter records.

 select * from user_details where gender="male";

**4. SQL WHERE Clause fetching only required columns**

select username,first_name, last_name from user_details where gender="male";

**5. SQL AND Operator**
* The WHERE clause can contain one or many AND operators.

select * from user_details where last_name="john" and gender="male";

**6. SQL OR Operator**
* The WHERE clause can contain one or more OR operators.

select * from user_details where first_name="david" or last_name="miller";

**7. SQL ORDER BY ASCENDING**
* The ORDER BY keyword is used to sort the result-set in ascending order.

select * from user_details where gender="male" order by user_id;

**8. SQL ORDER BY DESCENDING**
* To sort the records in descending order, use the DESC keyword.

select * from user_details where gender="male" order by user_id desc;

**9. SQL Aggregate Functions-MIN, MAX, COUNT, SUM, AVG**
* The MIN() function returns the smallest value of the selected column.
* The MAX() function returns the largest value of the selected column.
* The COUNT() function counts the total number of rows.
* The SUM() function returns the total sum of all values in the column.
* The AVG() function returns the average of all values in the column.

select min(user_id) from user_details;
select max(user_id) from user_details;
SELECT COUNT(user_id) from user_details;
SELECT SUM(user_id) from user_details;
SELECT AVG(user_id) from user_details;

**10. SQL GROUP BY Clause**
* Groups rows with the same values into summary rows.
* Used with aggregate functions like COUNT(), SUM(), AVG().

SELECT gender, COUNT(user_id) AS total_users FROM user_details GROUP BY gender;


**11. SQL HAVING Clause**
* Similar to WHERE, but used after GROUP BY.
* Filters grouped records based on conditions.

SELECT gender, COUNT(user_id) AS total_users FROM user_details GROUP BY gender HAVING total_users > 3;

## SQL JOINS
* A JOIN clause is used to combine rows from two or more tables, based on a related column between them.

1. INNER JOIN
2. LEFT JOIN
3. RIGHT JOIN
4. FULL JOIN

**NOTE:** Import tables first to perform joins

**1. INNER JOIN**
* The INNER JOIN keyword selects records that have matching values in both tables.

![image](https://github.com/user-attachments/assets/b1ec02f3-9cf1-4eac-969b-2628b25309b8)

**Syntax:**
SELECT column_name(s) FROM table1 INNER JOIN table2 ON table1.column_name = table2.column_name;

SELECT student_course.course_id, student_details.NAME, student_details.age FROM student_details
INNER JOIN student_course
ON student_details.roll_no = student_course.roll_no;


**2. LEFT JOIN**
* The LEFT JOIN keyword returns all records from the left table (table1), and the matching records from the right table (table2).
* The result is 0 records from the right side, if there is no match.

![image](https://github.com/user-attachments/assets/4f03f859-7a25-4ade-9160-29748e350d04)

**Syntax:**
SELECT column_name(s) FROM table1 LEFT JOIN table2 ON table1.column_name = table2.column_name;

SELECT student_course.course_id, student_details.NAME FROM student_details
LEFT JOIN student_course
ON student_details.roll_no = student_course.roll_no;


**3. RIGHT JOIN**
* The RIGHT JOIN keyword returns all records from the right table (table2), and the matching records from the left table (table1).
* The result is 0 records from the left side, if there is no match.

![image](https://github.com/user-attachments/assets/df76bbc3-40d1-4220-b997-73ae75508857)

**Syntax:**
SELECT column_name(s) FROM table1 RIGHT JOIN table2 ON table1.column_name = table2.column_name;

SELECT student_course.course_id, student_details.NAME FROM student_details
RIGHT JOIN student_course
ON student_details.roll_no = student_course.roll_no;

**4. FULL JOIN**
* The FULL OUTER JOIN keyword returns all records when there is a match in left (table1) or right (table2) table records.

![image](https://github.com/user-attachments/assets/6b0ede83-f1a3-4b46-aea5-3761e16a3e86)


**Syntax:**
SELECT Student.NAME,StudentCourse.COURSE_ID  FROM Student FULL JOIN StudentCourse ON StudentCourse.ROLL_NO = Student.ROLL_NO;

NO FULL JOIN

SELECT student_details.name, student_course.course_id
FROM student_details
LEFT JOIN student_course
ON student_course.roll_no = student_details.roll_no

UNION

SELECT student_details.name, student_course.course_id
