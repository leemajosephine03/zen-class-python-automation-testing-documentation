## Python Method Types
### 1. **Instance Method:**
An instance method is a method that operates on an instance of the class. It has access to the instance (via `self`) and can modify or access its attributes.

- **Definition:** It takes `self` as the first parameter, which refers to the instance.
- **Usage:** Called on an instance of the class, using the instance itself.

```python
class MyClass:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello, {self.name}"

obj = MyClass("Alice")
print(obj.greet())  # Calls the instance method
```

### 2. **Class Method:**
A class method is a method that operates on the class itself, not the instance. It is bound to the class and takes `cls` as the first parameter, which refers to the class.

- **Definition:** It takes `cls` as the first parameter, which refers to the class.
- **Usage:** Called on the class itself or on an instance, but typically used for factory methods or methods that need to modify the class state.

```python
class MyClass:
    count = 0
    
    def __init__(self, name):
        self.name = name
        MyClass.count += 1

    @classmethod
    def get_count(cls):
        return cls.count

obj1 = MyClass("Alice")
obj2 = MyClass("Bob")
print(MyClass.get_count())  # Calls the class method
```

### 3. **Static Method:**
A static method is a method that does not take either `self` or `cls` as the first parameter. It behaves like a regular function that is logically grouped within the class. It does not have access to the instance (`self`) or the class (`cls`) unless explicitly provided.

- **Definition:** It takes no special first parameter (no `self` or `cls`).
- **Usage:** Called on the class itself or an instance, but does not modify or access the class/instance state.

```python
class MyClass:
    
    @staticmethod
    def greet(message):
        return f"Message: {message}"

print(MyClass.greet("Hello, world!"))  # Calls the static method
```

## Operator Overloading with Examples

* Operator overloading allows you to define custom behavior for operators (like `+`, `-`, `*`, etc.) in user-defined classes.
* This makes your classes behave more intuitively with Python's built-in operators.
* In Python, operator overloading is achieved by defining special methods.
* These methods have double underscores (`__`) before and after their names, like `__add__`, `__sub__`, `__mul__`, etc.

### Example 1: Overloading the `+` Operator (Addition)

Let's overload the `+` operator to add two `Point` objects by defining the `__add__` method.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    # Overloading the + operator
    def __add__(self, other):
        # Adding the x and y values of the points
        return Point(self.x + other.x, self.y + other.y)
    
    def __repr__(self):
        return f"Point({self.x}, {self.y})"

# Creating two point objects
point1 = Point(1, 2)
point2 = Point(3, 4)

# Using the overloaded + operator
result = point1 + point2
print(result)  # Output: Point(4, 6)
```

### Example 2: Overloading the `-` Operator (Subtraction)

Now, let's overload the `-` operator to subtract one `Point` from another.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    # Overloading the - operator
    def __sub__(self, other):
        return Point(self.x - other.x, self.y - other.y)
    
    def __repr__(self):
        return f"Point({self.x}, {self.y})"

# Creating two point objects
point1 = Point(5, 8)
point2 = Point(2, 3)

# Using the overloaded - operator
result = point1 - point2
print(result)  # Output: Point(3, 5)
```


### Example 3: Overloading the `*` Operator (Multiplication)

You can also overload other operators. Let's look at how to overload the `*` operator for multiplication.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    # Overloading the * operator
    def __mul__(self, other):
        return Point(self.x * other, self.y * other)
    
    def __repr__(self):
        return f"Point({self.x}, {self.y})"

# Creating a point object
point = Point(3, 4)

# Using the overloaded * operator
result = point * 2
print(result)  # Output: Point(6, 8)
```

## 3. Python Polymorphism

* The word "polymorphism" means "many forms", and
* It refers to methods/functions/operators with the same name that can be executed on many objects or classes.

For example, say we have three classes: Car, Boat, and Plane, and they all have a method called move():
~~~python
class Car:
  def __init__(self, brand, model):
    self.brand = brand
    self.model = model

  def move(self):
    print("Drive!")

class Boat:
  def __init__(self, brand, model):
    self.brand = brand
    self.model = model

  def move(self):
    print("Sail!")

class Plane:
  def __init__(self, brand, model):
    self.brand = brand
    self.model = model

  def move(self):
    print("Fly!")

car1 = Car("Ford", "Mustang")       #Create a Car class
boat1 = Boat("Ibiza", "Touring 20") #Create a Boat class
plane1 = Plane("Boeing", "747")     #Create a Plane class

for x in (car1, boat1, plane1):
  x.move()
~~~

## 4. Python Encapsulation

Wrapping the methods and variables together into a single unit.

**Protected Member** - Protected members are those members of the class that cannot be accessed outside the class but can be accessed from within the class and its subclasses.

~~~python
class Base:
    def __init__(self):
        self._a = 5 # protected member

class Derived(Base):
    def __init__(self):
        Base.__init__(self) # constructor of parent class
        print("Calling protected member of base class: ",self._a)

        #modify the protected variable
        self._a = 10
        print("Calling modified protected member outside class: ",self._a)

x = Derived()
~~~

**Private Members**- similar to protected members, the difference is that the class members declared private should neither be accessed outside the class nor by any base class.
~~~python
class Base:
    def __init__(self):
        self.__a = 2 # private member
        self._b = 5 # protected member

class Derived(Base):
    def __init__(self):
        Base.__init__(self) # constructor of parent class
        # print(self.__a)
        print(self._b)

x = Derived()
" We can't access private variable"

# print(_b) & __a will not be executed.

# Using getter and setter
class Base:
    def __init__(self):
      self.__a = 2  # private member

    def get_item(self):
      return self.__a

    def set_item(self, value):
      self.__a = value

class Derived(Base):
    def __init__(self):
        Base.__init__(self)  # constructor of parent class

    def set_new_item(self, value):
       self.set_item(value)
       return self.get_item()

x = Derived()
print(x.get_item())
print(x.set_new_item(45))
~~~

## 5. Python Abstraction

* It's a concept that hides complex implementation details while exposing only essential information and functionalities to users. 
* A class containing one or more abstract methods is Abstract Class.
* Python provides the "abc module" to use the abstraction. abc - abstract base class.
* Abstract method don't have body. Both normal and abstract method can be inside a abstract class. Cannot create objects from abstract class.

~~~python
from abc import ABC  
  
class Polygon(ABC):   
  
   # abstract method   
   def sides(self):   
      pass  # dont have body
  
class Triangle(Polygon):   
   def sides(self):   
      print("Triangle has 3 sides")   
  
class Pentagon(Polygon):   
   def sides(self):   
      print("Pentagon has 5 sides")    
  
# Driver code   
t = Triangle()   
t.sides()    


p = Pentagon()   
p.sides()    
Output:
Triangle has 3 sides
Pentagon has 5 sides
~~~

### MINI-PROJECT 1 : Uber Price Calculation Application
* Write a Python program that calculates the fare of a ride based on the type of ride and the distance traveled. Implement inheritance and polymorphism to calculate the fare based on different rides. 

~~~ python
# Using Inheritance and Polymorphism
# Base class Ride
class Ride:
    def __init__(self, distance, base_fare):
        self.distance = distance  # Distance in kilometers
        self.base_fare = base_fare  # Base fare of the ride
    
    # Method to calculate the fare (can be overridden by subclasses)
    def calculate_fare(self):
        return self.base_fare + (self.distance * 10)  # Base fare + per km rate (10)

# Subclass RegularRide
class RegularRide(Ride):
    def __init__(self, distance):
        super().__init__(distance, 50)  # Base fare for regular ride is 50
    
    # Overriding calculate_fare for regular rides
    def calculate_fare(self):
        return self.base_fare + (self.distance * 10)  # 10 per km

# Subclass PremiumRide
class PremiumRide(Ride):
    def __init__(self, distance):
        super().__init__(distance, 100)  # Base fare for premium ride is 100
    
    # Overriding calculate_fare for premium rides
    def calculate_fare(self):
        return self.base_fare + (self.distance * 20)  # 20 per km for premium ride


# Testing the implementation
regular_ride = RegularRide(10)  # 10 km for regular ride
premium_ride = PremiumRide(10)  # 10 km for premium ride


# Printing the calculated fares
print(f"Regular Ride Fare: {regular_ride.calculate_fare()}")
print(f"Premium Ride Fare: {premium_ride.calculate_fare()}")

~~~
