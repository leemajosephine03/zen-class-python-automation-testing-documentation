## Git & GitHub


GitHub is a version control system

## Version Control System (VCS)

It tracks changes to the files and folders over the time
It helps us to collaborate with team members and individuals as well
Without VCS, it will be impossible to manage codes and changes inside it

## Git Branching

* Branch is Git/GitHub is the separate and new version of the main branch
* The “main” or “master” branch is always kept for production purposes only
* For testers/developers always create a separate branch from main branch


## Create a New Branch in Git and Push it to GitHub repository
~~~
git branch
git branch pat-automation-testers
git branch
git checkout pat-automation-testers
git add jenkins.py
git commit -m "added jenkins.py"
git push --set-upstream origin pat-automation-testers
~~~

## To add a new branch to GitHub Repository
1. Use ‘**git branch pytest1**’ to create a new branch inside repo
2. Use ‘**git checkout pytest1**’ to switch into new branch
3. Use ‘**git push --set-upstream origin pytest1**’ to push entire files/repo into new branch

## Git Revert
* The git revert command is used for undoing changes to a repository's commit history.
* **git revert HEAD**

## Git Reset
* Unstage a file while retaining the changes in working directory.
* **git reset --hard**

## Git Amend
* Change most recent Git commit message
* **git commit --amend -m "an updated commit message"**
