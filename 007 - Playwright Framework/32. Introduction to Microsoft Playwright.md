## What is Playwright?
- Playwright is an open-source automation framework for testing web applications.
- Developed by Microsoft.
- Supports modern browsers (Chromium, Firefox, and WebKit).
- Enables end-to-end testing, browser automation, and screen recording.

---

##  Difference between Playwright and Other Automation Tools
| Feature | Playwright | Selenium |
|:--------|:-----------|:---------|
| Browser Support | Chromium, Firefox, WebKit | All Major Browsers |
| Language Support | Python, Java, C#, JS/TS | Python, Java, C#, JS, Ruby, etc. |
| Auto-wait | Built-in | Manual waits often needed |
| Network Interception | Easy and built-in | Complex |
| Parallel Execution | Native support | Requires setup |

##  Playwright Architecture

![image](https://github.com/user-attachments/assets/7491cffa-b445-4993-abbd-bd6476648e1e)

- **Client:** Your test scripts (Python, JS, etc.)
- **Driver:** Playwright driver internally communicates with browsers.
- **Browser:** Real browser instances are controlled.
- Works through a **WebSocket** connection for real-time communication.

##  Why Python Language?
- Easy syntax, faster development.
- Great for beginners and pros.
- Large community and Playwright officially supports Python bindings.
- Easier integration with CI/CD pipelines and testing frameworks.

##  Create a New Repo and Clone to PyCharm
1. Create a new GitHub repository.
2. Clone it into your local machine using:
   ```bash
   git clone <your-repo-link>
   ```
3. Open the project folder in **PyCharm**.

##  Setting up Python and an IDE with a Sample Project
1. Ensure Python is installed (Recommended: Python 3.8+).
2. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Mac/Linux
   venv\Scripts\activate     # Windows
   ```
3. Install dependencies:
   ```bash
   pip install playwright pytest
   playwright install
   ```
4. Create your first test file inside a `tests/` directory.

##  Test Structure (AAA or Given/When/Then)
**AAA Structure: For Playwright**
- **Arrange:** Setup the context.
- **Act:** Perform the action.
- **Assert:** Verify the result.

**Given/When/Then Structure:**
- **Given:** Precondition setup.
- **When:** Action execution.
- **Then:** Expected outcome verification.

## Launching Browsers

Launch the first playwright automated browser

### Launch Chrome
~~~python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    # Channel can be "chrome", "msedge", other beta must installed separately
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    page.goto("https://www.guvi.in/")
    print(page.title())
    browser.close()
~~~

## Playwright Locators
In Playwright, **locators** are used to identify and interact with elements on a web page. Playwright offers **powerful, flexible ways** to define locators, making test automation robust and less flaky.


### 🔍 **Common Locator Types**

| Locator Type     | Syntax Example                                 | Description                                   |
| ---------------- | ---------------------------------------------- | --------------------------------------------- |
| **ID**           | `"#elementId"`                                 | Shortcut for CSS ID selection.                |
| **Class**        | `".className"`                                 | Shortcut for CSS class selection.             |
| **Attribute**    | `"input[name='username']"`                     | Select by any HTML attribute.                 |
| **CSS Selector** | `"css=div.classname"`                          | Matches elements using standard CSS.          |
| **XPath**        | `"xpath=//button[text()='Submit']"`            | XPath expression (less preferred).            |
| **Text**         | `"text='Submit'"` or `"button:has-text('Go')"` | Matches by visible text.                      |
| **Role**         | `"role=button[name='Submit']"`                 | Accessible roles (ARIA-based).                |
| **Label**        | `"label=Username"`                             | Matches a label associated with a form field. |
| **Placeholder**  | `"input[placeholder='Email']"`                 | Matches placeholder text.                     |
| **Nth Match**    | `"div.item >> nth=0"`                          | First matched element (zero-based index).     |

---

### 🔧 **Examples in Playwright Python**

```python
# By ID
page.fill("#username", "admin")

# By CSS Selector
page.click("button.submit-btn")

# By Text
page.click("text='Login'")

# By XPath
page.click("xpath=//a[contains(text(), 'Home')]")

# By Role (ARIA)
page.get_by_role("button", name="Submit").click()

# By Label
page.get_by_label("Username").fill("user123")

# By Placeholder
page.locator("input[placeholder='Enter Email']").fill("email@example.com")

```

## QAV Signup Form Filling - Playwright

```python
from playwright.sync_api import sync_playwright
from time import sleep

# URL of the QAVBOX signup page
URL = "https://qavbox.github.io/demo/signup/"

# Test data
FULL_NAME = "Tester"
EMAIL = "tester@gmail.com"
TELEPHONE_NO = "9876543120"

def test_qavbox_signup():
    with sync_playwright() as p:
        # Launch browser
        browser = p.chromium.launch(headless=False)
        context = browser.new_context()
        page = context.new_page()

        # Navigate to the page
        page.goto(URL)

        # Fill form fields
        page.fill("input[name='uname']", FULL_NAME)
        page.fill("#email", EMAIL)
        page.fill("#tel", TELEPHONE_NO)

        # Upload file (make sure this file path exists)
        page.set_input_files("input[name='datafile']", "D:\Automation\PlaywrightDemo\FillingForms\profile_image.png")

        # Gender selection
        page.select_option("select[name='sgender']", "Male")

        # Select Years of Experience
        page.check("input[value='one']")

        # Select Interests
        page.check("input[value='manualtesting']")
        page.check("input[value='automationtesting']")

        # Select Tools
        page.select_option("select#tools", "Selenium")

        # Click Submit
        page.click("input[type='submit']")

        # Wait to observe result
        # sleep(5)

        print("SUCCESS, QAVBOX Signup Form Filled!")

        # Close browser
        browser.close()

# # Run the function
# test_qavbox_signup()

```
