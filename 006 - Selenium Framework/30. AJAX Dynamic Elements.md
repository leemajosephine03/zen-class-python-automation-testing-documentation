## 30. AJAX Dynamic Elements
* Working with AJAX elements using Selenium


## What is AJAX?
AJAX (Asynchronous JavaScript and XML) allows web pages to be updated asynchronously by exchanging data with a web server 
behind the scenes. This means a page can update without reloading, making element loading dynamic and unpredictable.

## AJAX Examples
**1. Google Maps**

**AJAX Features:**
* Dynamic loading of map tiles and search results without full page reloads.
* Real-time updates when panning or zooming the map.​


**2. Gmail**

**AJAX Features:**
* Asynchronous loading of emails and conversations.
* Real-time updates for new emails and chat messages.​


**3. Amazon**

**AJAX Features:**
* Dynamic product search suggestions as you type.
* Real-time updates to shopping cart and product availability.​


## Key Challenges with AJAX in Selenium
* Elements may not be available immediately in the DOM.
* Elements may change or reload after interactions.
* Using time.sleep() is unreliable — prefer WebDriverWait and expected_conditions.


## Common Expected Conditions
* presence_of_element_located
* visibility_of_element_located
* element_to_be_clickable
* invisibility_of_element_located
* text_to_be_present_in_element


## AJAX Example 1
~~~ python
"""
https://testpages.eviltester.com/styled/basic-ajax-test.html
Below is a hands-on example showing how to handle the dynamic AJAX dropdown on the EvilTester “Basic Ajax Example” page using Python + Selenium. We’ll:

1.Open the page.
2.Select a category to trigger the AJAX call.
3.Wait for the “Language” dropdown to be populated.
4.Print out the loaded options.
"""
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait, Select
from selenium.webdriver.support import expected_conditions as EC


# 1. Launch browser and navigate
driver = webdriver.Chrome()
driver.get("https://testpages.eviltester.com/styled/basic-ajax-test.html")
driver.maximize_window()

# 2. Build the list of categories (skip the empty placeholder)
wait = WebDriverWait(driver, 10)
initial_select = Select(driver.find_element(By.ID, "combo1"))

# store all categories here
categories = ["Web", "Desktop", "Server"]

# 3. Iterate categories, re-locate dropdowns each time, and print languages
for category in categories:
    # Re-find Category <select> and select the current category
    category_elem = driver.find_element(By.ID, "combo1")
    Select(category_elem).select_by_visible_text(category)

    wait.until(EC.invisibility_of_element_located((By.XPATH, '//span[@style="display: block;"]')))

    # Wait for at least one AJAX-loaded <option> in the Language dropdown
    wait.until(EC.presence_of_all_elements_located(
        (By.XPATH, '//select[@id="combo2"]/option')
    ))

    # Re-find Language <select> and gather its options
    language_elem = driver.find_element(By.ID, "combo2")

    # using list comprehension
    languages = [opt.text for opt in Select(language_elem).options]

    # Output results
    print(f"Category: {category}")
    for lang in languages:
        print(f"Language: {lang}")
    print("-------------------------")

# 4. Cleanup
driver.quit()

~~~


## AJAX Example 2

~~~ python
"""
Program : Coding Challenge to extract AJAX Data
Caveats : AJAX Data
Website : https://www.worldometers.info/world-population/
"""

from selenium import webdriver
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service
from selenium.webdriver.common.by import By
from selenium.webdriver.common.action_chains import ActionChains
from selenium.common.exceptions import NoSuchElementException
from selenium.common.exceptions import ERROR_URL


class Locators:
    total_population_locator = '//div[@class="col-span-3"]//span[@class="rts-counter"]' 
    todays_birth = '//div[text()="Births today"]//parent::div//span[@class="rts-counter text-2xl font-bold"]'


class WorldPopulation(Locators):
    url = "https://www.worldometers.info/world-population/"
    driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))
    action = ActionChains(driver)

    def start(self):
        try:
            self.driver.maximize_window()
            self.driver.get(self.url)
            self.driver.implicitly_wait(10)
            return True
        except ERROR_URL as error:
            print(error)

    # Display the Total Population
    def world_population(self):
        try:
            total_population = []
            while True:
                total_population_count = self.driver.find_element(by=By.XPATH, value=self.total_population_locator)
                total_population.append(total_population_count)
                for data in total_population:
                    print(f"Current World Population: {data.text}")
        except NoSuchElementException as error:
            print(error)
        finally:
            self.driver.quit()

    # Display today's Birth
    def birth_today(self):
        try:
            birth_today = []
            while True:
                total_population_count = self.driver.find_element(by=By.XPATH, value=self.todays_birth)
                birth_today.append(total_population_count)
                for data in birth_today:
                    print(f"Todays Birth: {data.text}")
        except NoSuchElementException as error:
            print(error)
        finally:
            self.driver.quit()


if __name__ == "__main__":
    world_population = WorldPopulation()
    world_population.start()
    # world_population.world_population()
    world_population.birth_today()
~~~
