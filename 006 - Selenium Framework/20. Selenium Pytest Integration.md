## How to write Test Cases 
* Software testing is a possess of validating and verifying the working of an web-application
* It helps us to find the errors, bugs
* A test case is a predefined format used in software testing for verifying and validating a web application.

## Parameters for a test-case
* Test Scenario Name
* Test case ID
* Tester’s Name
* Test Description
* Test Steps
* Prerequisites
* Test Data
* Test Expected Result
* Test Actual Result
* Comments

## Test Scenario
* It is a small description of what needs to be done or tested
* It is generally a “One Line Statement”
* They are derived from SRS document according to SDLC
* It focuses on “What To Be Tested ?”
* They take less time to create and maintain

## Positive Test Case
* They are the test-cases which are designed to test the web application with valid input and with valid conditions
* It tells us whether the application behaves as expected and meets the requirements laid down

## Negative Test Case
* They are the test-cases which are designed to test the web application with invalid input and with invalid conditions
* It helps us to ensure whether the application can handles errors and unexpected situations gracefully or not
* It helps us to find out the potential points of failure for our application

## Pytest Framework
* It is a Python framework which is used to generate test-reports based on the code which you have tested

**Install Pytest**
	1. pip install pytest
 
	2. pip install pytest-html

**Pytest-html** is used to generate HTML based test-case reports which you will send to your developer and other stakeholders.
Always create a file with “test_” for creating a Pytest file

## Pytest - Selenium Python 
~~~python
"""
HomePage.py - Python Selenium codes for automation only
"""
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

class Suman:
   def __init__(self, url):
       self.url = url
       self.driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))

   # start the Python Selenium automation
   def start_automation(self):
       try:
           self.driver.maximize_window()
           self.driver.get(self.url)
           return True
       except:
           print("ERROR : Unable to start the Python Selenium Automation")
           return False

   # shutdown the entire Python Selenium automation
   def shutdown(self):
       self.driver.close()

   # fetch the title of the web-application
   def fetch_title(self):
       if self.start_automation():
           return self.driver.title
       else:
           print("ERROR : Unable to fetch the title of web application")
           return False

   # fetch the URL of the web application
   def fetch_url(self):
       if self.start_automation():
           return self.driver.current_url
       else:
           print("ERROR : Unable to fetch the URL of the web application")
           return False
~~~

## test_homepage.py
~~~python
"""
test_homepage.py - Pytest test-case for verifying & validating your Python Selenium automation codes
"""
from HomePage import Suman
import pytest

url = "https://www.guvi.in/"
suman = Suman(url)

# Positive Test Case - Verify the URL to be https://www.guvi.in
def test_positive_url():
   testing_data = url
   assert suman.fetch_url() == testing_data
   print("SUCCESS : Test URL passes")

# Negative Test Case - Verify the URL Not to be https://www.guvi.in
def test_negative_url():
   testing_data = "https://www.suman.in"
   assert suman.fetch_url() != testing_data
   print("SUCCESS : Test failed")

# Close the Python Selenium automation
def test_close():
   assert suman.shutdown() == None
   print("SUCCESS : Python Selenium automation was success")

~~~
