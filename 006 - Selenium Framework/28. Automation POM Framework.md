## Page Object Model
* A Page Object Model (POM) is a design pattern for writing clean and well structured codes.
* It is a way of using objects to represent elements on the page.
* Separate python classes are created to represent the web pages.
* This enables to write code that is simple and easy to understand.
* It also helps to keep our tests well-structured and understandable.

## Advantages of POM 
* The POM helps you write tests that are easy to understand and maintain.
* If something got changed on any page, we could easily find the functions and locators that need to be changed by that page class.
* The POM can help with collaboration between team members and improve the efficiency.
* Using POM, we can reuse our functions in different test scripts by importing them from Page Class.

## HomePage.py
~~~python
"""
HomePage.py


PageObjects File
"""
from selenium import webdriver
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.service import Service

# import data and locators
from TestData.data import OrangeHRM_Data
from TestLocators.locators import OrangeHRM_Selectors


class HomePage():

   driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))


   def start(self):
       self.driver.maximize_window()
       self.driver.implicitly_wait(10)
       self.driver.get(OrangeHRM_Data.url)
       return True


   def login(self):
       self.driver.find_element(by=By.NAME, value=OrangeHRM_Selectors.username_box).send_keys(OrangeHRM_Data.username)
       self.driver.find_element(by=By.NAME, value=OrangeHRM_Selectors.password_box).send_keys(OrangeHRM_Data.password)
       self.driver.find_element(by=By.XPATH, value=OrangeHRM_Selectors.submit_button).click()
       return True


   def shutdown(self):
       self.driver.quit()
       return None

~~~

## Working with Toast Messages
* Toast Message : It is a kind of temporary messages which gets Flashed on your web-browser when a certain actions happen
* They are commonly seen when any CRUD operations are carried out by the used on the web application
* Sometimes they are used to display a simple small temporary messages
* Kindly note that they are NOT JAVASCRIPT ALERT !

## ToastPage.py
~~~python
"""
MINI-PROJECT : Working with Toast Messages & POM


ToastPage.py
"""
from selenium import webdriver
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.service import Service
from selenium.common.exceptions import NoSuchElementException
from selenium.common.exceptions import ElementNotVisibleException


class Data:
   url = "https://sumantoastmessage.netlify.app/"


class Locators:
   toast_message ="//div[@class='column']//span[text()='Success: This is a success toast.']"
   success_button = "success"


class ToastMessages(Data, Locators):


   driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))


   def start(self):
       self.driver.maximize_window()
       self.driver.implicitly_wait(10)
       self.driver.get(self.url)
       return True


   def success_toast_message(self):
           try:
               self.driver.find_element(by=By.ID, value=self.success_button).click()
               success_text = self.driver.find_element(by=By.XPATH, value=self.toast_message).text
               return success_text
           except (ElementNotVisibleException, NoSuchElementException) as error:
               print(error)
           finally:
               self.driver.quit()

~~~
