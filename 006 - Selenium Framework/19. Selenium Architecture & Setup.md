## Architecture of Selenium 3
* The architecture of Selenium 3 is based on the JSON Wire Protocol.
* JSON means JavaScript Object Notation.
* The activity of JSON Wire Protocol is to facilitate information between Client and Server through HTTP (Hypertext Transfer Protocol).
* Selenium Client sends a selenium request & JSON Wire Protocol receives the same request through HTTP.
* In the end, “Server” returns the “Response” and “Client” receives the same.

## Architecture of Selenium 4
* The architecture of Selenium 4 is similar to Selenium 3, it uses W3C protocol instead of JSON wire protocol for direct communication between Client Libraries and Browser Drivers.
* W3C stands for the World Wide Web Consortium, an international community that develops and maintains standards and guidelines for the World Wide Web.
* By following this standard protocol, the client directly communicate between browser drivers and process the response.

## Python Virtual Environment
* A virtual environment is an isolated environment created on top of an existing Python installation.
* It provides isolated environments for each project, ensuring that the dependencies for one project don’t interfere with those of another.
* They allow you to install, upgrade, or remove packages without affecting the global Python installation.
* Easy to share projects with others without worrying about dependencies.

## Working with multiple browsers 

**Python Selenium using Google Chrome Browser**
~~~python
"""
Python Selenium using Google Chrome Browser
"""

from selenium import webdriver
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service

class SumanAutomationChrome:


   def __init__(self, web_url):
       self.url = web_url
       self.driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))

   # boot the web app
   def start(self):
       self.driver.maximize_window()
       self.driver.get(self.url)

   # shutdown the automation
   def stop(self):
       self.driver.close()

if __name__ == "__main__":
   url = "https://www.guvi.in"
   suman = SumanAutomationChrome(url)
   suman.start()
   suman.stop()

~~~
