**# Introduction to Selenium APIs**

## What is Selenium?
Selenium is an open-source framework used for automating web applications. It provides various APIs to interact with web elements, perform browser automation, and execute test scripts efficiently.

## Selenium APIs Overview
Selenium APIs allow interaction with web browsers via different programming languages such as Java, Python, and C#. The main components include:
- **Selenium WebDriver**: Automates browser actions.
- **Selenium Grid**: Enables parallel execution across multiple browsers.
- **Selenium IDE**: A record-and-playback tool for creating test cases.

**# Firefox & Chrome API**

## 1. Firefox API (Using GeckoDriver)
### Setting Up Selenium with Firefox
To automate Firefox, Selenium uses **GeckoDriver**, which acts as a bridge between Selenium and the Firefox browser.

### Example: Launching Firefox and Navigating to a Website
```python
from selenium import webdriver
from selenium.webdriver.firefox.service import Service
from selenium.webdriver.firefox.options import Options

# Set up Firefox options
options = Options()
options.add_argument("--headless")  # Run Firefox in headless mode

# Define the service with GeckoDriver path
service = Service("path/to/geckodriver")

# Initialize the WebDriver
browser = webdriver.Firefox(service=service, options=options)

# Open a website
browser.get("https://www.google.com")

# Print the title
print("Page Title:", browser.title)

# Close the browser
browser.quit()
```
### Key Features of Firefox API:
- Supports headless execution.
- Provides options for managing profiles and preferences.
- Enables user-agent modifications.

## 2. Chrome API (Using ChromeDriver)
### Setting Up Selenium with Chrome
To automate Chrome, Selenium uses **ChromeDriver**, which communicates with the Chrome browser.

### Example: Launching Chrome and Performing a Search
```python
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys

# Set up Chrome options
options = Options()
options.add_argument("--headless")  # Run Chrome in headless mode
options.add_argument("--disable-gpu")

# Define the service with ChromeDriver path
service = Service("path/to/chromedriver")

# Initialize the WebDriver
browser = webdriver.Chrome(service=service, options=options)

# Open Google
browser.get("https://www.google.com")

# Perform a search
search_box = browser.find_element(By.NAME, "q")
search_box.send_keys("Selenium WebDriver")
search_box.send_keys(Keys.RETURN)

# Print the title
print("Page Title:", browser.title)

# Close the browser
browser.quit()
```
### Key Features of Chrome API:
- Allows headless mode for faster execution.
- Provides extensive debugging options.
- Supports multiple extensions and experimental features.

## All Selenium API's
Selenium provides various API methods to interact with web elements and automate browser actions. Below are the key Selenium API methods:

### **1. Browser Navigation Methods**
- `get(url)`: Opens the specified URL.
- `back()`: Navigates back in the browser history.
- `forward()`: Navigates forward in the browser history.
- `refresh()`: Refreshes the current page.

### **2. Web Element Interaction Methods**
- `find_element(By, value)`: Finds a single element.
- `find_elements(By, value)`: Finds multiple elements matching the criteria.
- `click()`: Clicks on an element.
- `send_keys(value)`: Enters text into an input field.
- `clear()`: Clears the text from an input field.
- `submit()`: Submits a form.

### **3. Web Element Properties & Attributes**
- `text`: Retrieves the visible text of an element.
- `get_attribute(name)`: Retrieves the value of an element’s attribute.
- `is_displayed()`: Checks if an element is visible.
- `is_enabled()`: Checks if an element is enabled.
- `is_selected()`: Checks if an element (checkbox/radio) is selected.

### **4. Handling Alerts & Popups**
- `switch_to.alert`: Switches to an alert box.
- `accept()`: Accepts an alert (OK).
- `dismiss()`: Dismisses an alert (Cancel).
- `send_keys(value)`: Enters text into an alert prompt.
- `text`: Retrieves the text of the alert.

### **5. Handling Frames & Windows**
- `switch_to.frame(name/index)`: Switches to a specified frame.
- `switch_to.default_content()`: Switches back to the main page from a frame.
- `switch_to.window(window_handle)`: Switches to a specified browser window.

### **6. Handling Cookies**
- `get_cookies()`: Retrieves all cookies.
- `get_cookie(name)`: Retrieves a specific cookie by name.
- `add_cookie(cookie_dict)`: Adds a cookie.
- `delete_cookie(name)`: Deletes a specific cookie.
- `delete_all_cookies()`: Deletes all cookies.

### **7. Wait Methods**
- `implicitly_wait(time)`: Waits for a specified amount of time before throwing an exception.
- `WebDriverWait(driver, time).until(condition)`: Explicit wait for a condition.
- `WebDriverWait(driver, time).until_not(condition)`: Waits until a condition is no longer true.

### **8. Executing JavaScript**
- `execute_script(script, args)`: Runs JavaScript code in the browser.
- `execute_async_script(script, args)`: Runs asynchronous JavaScript code.


### API's Example

~~~python
Example: Automating a Demo Webpage - https://the-internet.herokuapp.com/
Form Validation

from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.common.by import By
from time import sleep

class Data:
    url = "https://the-internet.herokuapp.com"
    username = "tomsmith"
    password = "SuperSecretPassword!"

class Locators:
    username_locator = 'username' # ID
    password_locator = 'password' # ID
    login_locator = 'radius' # Class Name
    message_locator = 'flash'  # Class Name

class APIDemo(Data, Locators):
       
    def __init__(self):
        # Set up Chrome options
        chrome_options = Options()
        chrome_options.add_argument("--headless")
        self.driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))

    def launch_automation(self):
        # Open a demo page
        self.driver.get(Data.url)
        self.driver.maximize_window()
        sleep(2)

        # Click on "Form Authentication"
        self.driver.find_element(By.LINK_TEXT, "Form Authentication").click()

        # Locate input fields and enter credentials
        username = self.driver.find_element(by=By.ID, value=Locators.username_locator)
        username.send_keys(Data.username)

        password = self.driver.find_element(by=By.ID, value=Locators.password_locator)
        password.send_keys(Data.password)

        login_button = self.driver.find_element(by=By.CLASS_NAME, value=Locators.login_locator) 
        login_button.click()

        # Print the success message
        confirmation = self.driver.find_element(by=By.CLASS_NAME, value=Locators.message_locator).text
        print(confirmation)
        
if __name__ == "__main__":
    myAPI = APIDemo()
    myAPI.launch_automation()
~~~

### API's Chrome and Firefox 

~~~python
# Choosing chrome or firefox

from selenium import webdriver
# import chrome service and driver manager
from selenium.webdriver.chrome.service import Service as ChromeService
from webdriver_manager.chrome import ChromeDriverManager
# import firefox service and driver manager
from selenium.webdriver.firefox.service import Service as FirefoxService
from webdriver_manager.firefox import GeckoDriverManager
# import chrome and firefox options
from selenium.webdriver.chrome.options import Options as ChromeOptions
from selenium.webdriver.firefox.options import Options as FirefoxOptions
from selenium.webdriver.common.by import By
from time import sleep

class Data:
    url = "https://the-internet.herokuapp.com"
    username = "tomsmith"
    password = "SuperSecretPassword!"

class Locators:
    username_locator = 'username' # ID
    password_locator = 'password' # ID
    login_locator = 'radius' # Class Name
    message_locator = 'flash'  # Class Name

class APIDemo(Data, Locators):
       
    def __init__(self, browser_name):
        # Set up Chrome options
        if browser_name.lower() == "chrome":
            chrome_options = ChromeOptions()
            chrome_options.add_argument("--headless")  # Run Chrome in headless mode
            self.driver = webdriver.Chrome(service=ChromeService(ChromeDriverManager().install()), options=chrome_options)
        elif browser_name.lower() == "firefox":
            firefox_options = FirefoxOptions()
            firefox_options.add_argument("--headless")  # Run Firefox in headless mode
            self.driver = webdriver.Firefox(service=FirefoxService(GeckoDriverManager().install()), options=firefox_options)
        else:
            raise ValueError("Unsupported browser! Choose 'chrome' or 'firefox'.")


    def launch_automation(self):
        # Open a demo page
        self.driver.get(Data.url)
        self.driver.maximize_window()
        sleep(2)

        # Click on "Form Authentication"
        self.driver.find_element(By.LINK_TEXT, "Form Authentication").click()

        # Locate input fields and enter credentials
        username = self.driver.find_element(by=By.ID, value=Locators.username_locator)
        username.send_keys(Data.username)

        password = self.driver.find_element(by=By.ID, value=Locators.password_locator)
        password.send_keys(Data.password)

        login_button = self.driver.find_element(by=By.CLASS_NAME, value=Locators.login_locator) 
        login_button.click()
        sleep(5)       

        # Print the success message
        confirmation = self.driver.find_element(by=By.CLASS_NAME, value=Locators.message_locator).text
        print(confirmation)
        
if __name__ == "__main__":
    # browser_choice = "chrome"
    browser_choice = "firefox"
    myAPI = APIDemo(browser_choice)
    myAPI.launch_automation()
~~~
