## 📌 Selenium Waits

### 1. **Implicit Wait**
Sets a default wait time for locating elements.

```python
from selenium import webdriver

driver = webdriver.Chrome()
driver.implicitly_wait(10)  # seconds
driver.get("https://example.com")
element = driver.find_element("id", "my-element")
```

---

### 2. **Explicit Wait**
Waits for a specific condition using `WebDriverWait`.

```python
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 10)
element = wait.until(EC.presence_of_element_located((By.ID, "my-element")))
```

---

### 3. **Fluent Wait**
Polls the DOM at regular intervals until the condition is met.

```python
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 20, poll_frequency=2)
element = wait.until(EC.element_to_be_clickable((By.ID, "submit-btn")))
```

---

### 4. **Expected Conditions**
Predefined conditions used with explicit or fluent waits like:
- `element_to_be_clickable`
- `visibility_of_element_located`
- `presence_of_element_located`

## 🕹 Handling Web Elements

### 1. **Dropdowns**

```python
from selenium.webdriver.support.ui import Select

select = Select(driver.find_element(By.ID, "dropdown"))
select.select_by_visible_text("Option 1")
```

---

### 2. **HTML Tables**

```python
rows = driver.find_elements(By.XPATH, "//table[@id='data']//tr")
for row in rows:
    columns = row.find_elements(By.TAG_NAME, "td")
    for column in columns:
        print(column.text)
```

---

### 3. **Frames & Windows**

```python
driver.switch_to.frame("frameName")
driver.switch_to.default_content()

driver.switch_to.window(driver.window_handles[1])
```

---

### 4. **AJAX Elements**
Use **waits** to handle dynamic content.

```python
element = WebDriverWait(driver, 10).until(
    EC.presence_of_element_located((By.ID, "ajax-content"))
)
```

---

### 5. **Alerts**

```python
alert = driver.switch_to.alert
print(alert.text)
alert.accept()
```

## 🎯 Advanced Web Interactions

actions = ActionChains(driver)
element = driver.find_element(By.ID, "hover")

## 🔍 XPath Concepts

### 1. **What is XPath?**
A query language for navigating through elements in XML/HTML documents.

---

### 2. **Types of XPath**
- **Absolute XPath**: `/html/body/div[1]/input`
- **Relative XPath**: `//input[@id='username']`

---

### 3. **Dynamic XPath**

```python
# using contains()
element = driver.find_element(By.XPATH, "//button[contains(text(), 'Submit')]")
```

---

### 4. **Parent-Child Relationship**

```python
driver.find_element(By.XPATH, "//div[@class='parent']/child::p")
```

---

### 5. **Siblings**

```python
driver.find_element(By.XPATH, "//label[text()='Username']/following-sibling::input")
```

## 🌐 Working with Browser Capabilities - Headless Browsing

### Desired Capabilities

Used to define custom browser settings.

from selenium import webdriver

options = Options()
options.add_argument("--disable-notifications")
driver = webdriver.Chrome(options=options)

## 🧪 Test Framework Integration

### 1. **Pytest**

```python
import pytest
from selenium import webdriver

@pytest.fixture
def setup():
    driver = webdriver.Chrome()
    yield driver
    driver.quit()

def test_title(setup):
    setup.get("https://example.com")
    assert "Example Domain" in setup.title
```

## 🧱 Automation Frameworks

### 1. **Page Object Model (POM)**

```python
class LoginPage:
    def __init__(self, driver):
        self.driver = driver
        self.username_input = driver.find_element(By.ID, "username")
    
    def login(self, username):
        self.username_input.send_keys(username)
```

---

### 2. **Data-Driven Testing (DDTF)**

```python
import csv

with open('data.csv') as file:
    reader = csv.reader(file)
    for row in reader:
        print(row[0], row[1])
```

---

### 3. **Keyword-Driven Testing (KDTF)**

Using keyword-action mapping:

```python
def execute(keyword):
    if keyword == "OPEN":
        driver.get("https://example.com")
    elif keyword == "CLICK":
        driver.find_element(By.ID, "btn").click()
```

## 🚫 Common Python Selenium Exceptions

- **NoSuchElementException**: Element not found.
- **TimeoutException**: Element not found within wait time.
- **StaleElementReferenceException**: DOM updated, element no longer attached.
